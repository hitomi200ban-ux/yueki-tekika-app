# 画像ファイルについて

このフォルダには輸液チャンバーの画像を配置してください。

## 必要なファイル

- **iv_chamber.png** - 輸液チャンバーのリアルアニメ調画像
  - 背景: 透明（PNG形式）
  - 推奨サイズ: 幅200px程度
  - 内容: 点滴チャンバー（滴下筒）の画像

## 画像の準備方法

1. リアルアニメ調の輸液チャンバー画像を用意
2. 背景を透明にして PNG 形式で保存
3. `iv_chamber.png` というファイル名で、このフォルダに配置

## 注意事項

- 雫が落ちる位置は、画像の下から約20pxの位置に設定されています
- 画像サイズに応じて、CSSの `#dropArea` の `bottom` 値を調整してください
